## `01` &nbsp;Sobre mim

Programo desde **2013** e atuo como **full stack desde 2020**, mas é no **back-end** que eu realmente me encontro: lógica, performance e a estrutura que mantém a aplicação de pé.

- ⚙️ &nbsp;**APIs, autenticação, integrações e automações** são o meu dia a dia
- 🚀 &nbsp;Fundador da **[Core System](https://www.coresystem.dev)**, com soluções sob medida para servidores FiveM
- 🎮 &nbsp;No cenário **FiveM** desde **2019**, hoje também em **RedM**
- 🔁 &nbsp;Metodologias ágeis, versionamento com Git e deploy automatizado
- 💙 &nbsp;Stack favorita: **React + TypeScript**

> Movido por desafios: gosto de construir sistemas inteligentes, bem estruturados e que resolvam problemas de verdade, com **foco em performance, segurança e escalabilidade**.
